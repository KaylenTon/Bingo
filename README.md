# Bingo Card Project

There are two Bingo generation variations.

### Basic 75-Ball Bingo

Standard 75-ball Bingo cards using randomly generated numbers.

- 5 × 5 grid
- `B` numbers: 1–15
- `I` numbers: 16–30
- `N` numbers: 31–45
- `G` numbers: 46–60
- `O` numbers: 61–75
- Center space is `FREE`
- Cards are randomized and unique

### T/F Statements Bingo

A customized Bingo format using TRUE/FALSE statements instead of numbers.

- 5 × 5 grid
- Center space is `FREE`
- TRUE and FALSE statements are randomly assigned
- Cards are randomly generated and unique
- A predefined number of cards are guaranteed winners
- Remaining cards are guaranteed not to contain a winning pattern
